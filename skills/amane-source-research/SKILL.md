# 来源调研

## 目的

调研的产出是一份可直接据以决策的报告, 回答两件事: 该来源是否接入, 以及接入时放在哪条路由、贡献哪些字段、处于什么优先级. 报告中不允许出现无法据以决策的内容.

本规范只规定**调研什么**与**报告什么**. 调研手段(直连请求、公开 API、无头浏览器、镜像数据、人工抽样)不作限定, 手段选择与执行过程不写入报告.

调研范围涵盖影片元数据来源、演员档案来源与播放来源; 播放来源另见「播放来源补充项」.

## 调研项

以下各组均为必须回答的内容. 每项结论必须给出可复现的证据: 数字写明样本量与抽样口径, 边界写明反例; 测不到的内容写明未测及原因.

### 内容范围与边界

- 收录范围: 类型分布(有碼 / 無碼 / 素人 / VR / FC2 / 欧美 / 国产 / 动画)、厂牌与系列分布、条目总量与时间跨度.
- 不收录范围: 对每一类各抽取若干番号给出有无结果; 禁止依据站点导航、站点自述或首页推测边界.
- 形态判断: 它是全量目录, 还是只镜像发布流; 是否含早年存量.
- 与上游目录的关系: 哪些条目是上游目录的搬运, 哪些是本来源的加工产物.

### 活跃度

- 最新条目的时间、最近若干月的新增数量、历史起始时间.
- 停更迹象: 更新间隔是否变长, 是否存在成片缺号.
- 条目是否事后修订, 修订的节奏与粒度, 修订是否改变字段取值.

### 访问难度

- 反爬形态及各自的触发条件: 拦截页、JS 挑战、验证码、年龄墙、地域限制.
- 测试节点的地域必须写明; 可达性结论只在所测节点上成立.
- 凭据需求: 账号、cookie、token、代理, 以及凭据缺失时的行为.
- 数据来源: 页面与公开 API 分别提供哪些字段, 哪个更适合采集.
- 稳定性: 延迟、失败率、限速与并发表现、错误形态.
- robots、站点条款、联盟或付费限制.

### 字段完整度与质量

- 逐字段出现率(样本量 + 抽样口径), 并写明字段语义: 片商与发行商的区分、番号与站内 ID 的区分、演员名单的性别与多值语义.
- 番号映射: 能否由番号直达条目, 存在哪些形态, 命中由哪个字段校验, 是否存在误命中.
- 脏数据形态: 占位符、别名、多值分隔、缺字段默认值, 以及解析上必须如何处理它们.
- 与权威来源的一致性: 上游有官方数据的条目必须交叉核对, 一致与不一致各自给出样本.
- 增量价值: 逐字段区分本来源独有与与既有来源重复; 重复字段不构成接入理由.

### 多语言

- 支持的语言集合, 以及标题、简介、演员名各自的语言.
- 是否存在机器翻译、多语言入口与语言切换.
- 结论须给出 descriptor 的 `multi_language` trait 取值与理由.

### 接入面

- 类型路由: 纳入哪些类型, 不纳入哪些类型及理由.
- 字段取舍: 取用哪些字段, 不取哪些字段, 与既有来源重叠时的处置.
- 优先级位置: 在 `field_priority` 各字段链中的位置与理由. 涉及演员字段时必须核对聚合语义(名单由首个成功源锁定, 其后各源只补性别, 不做合集), 并据此说明「填空」如何实现.
- 配置: 需要的凭据、站点参数与连通性探测入口; 入口不是站点根时必须指出.
- 能力声明: 影片元数据 / 演员档案 / 播放.

### 播放来源补充项

- 探测粒度与候选流的来源, 以及一条流不可播时的呈现.
- 鉴权与签名有效期, 以及结果可复用的时长.
- 地域限制与上游并发限制.
- 流类型(HLS / 逐字节码流)与字幕轨道.

### 风险与未验证项

- 不可核对的结论, 以及结论依赖的单点(单一数据源、单人运营、无 API 契约).
- 改版即失效的解析点.
- 本次未能验证的内容与原因.

## 报告结构

报告按以下顺序组织, 并与「调研项」逐组对应: 每组的结论都必须出现, 无内容时标记为「无」.

1. **结论**: 是否接入; 接入则给出路由、字段与优先级; 不接入则给出可证伪的理由.
2. **依据**: 按调研项分组陈述, 每项附数字、样本量与反例.
3. **接入方案**: 路由、字段、优先级、配置、能力声明.
4. **未验证项**: 逐条写明未验证内容与原因.

## 判断规则

- 能被搜索命中、能返回详情页, 不构成纳入默认路由的理由(见 [content-routes.md](../../docs/dev/content-routes.md)).
- 字段与既有来源完全重复且无增量时, 不建议接入.
- 既有来源已覆盖的能力, 只在能补齐具体缺口(某类型缺字段、某语种缺标题)时才考虑接入.
- 准确性无法核对的字段只能放在填空位置, 不得排在有官方数据的来源之前.
- 会把无关番号拼成「看起来像详情页」的来源不纳入默认路由.

## 禁止事项

- 禁止未经反例验证就断言收录边界.
- 禁止以单个样本代表全量; 禁止只依据首页、搜索结果或站点自述下结论.
- 禁止在报告中写入调研手段、工具选择、命令与执行过程.
- 禁止省略样本量, 禁止把未验证项写成结论.
- 禁止在报告之外另行给出与报告冲突的推荐.
