# 表达规范

> 适用范围: 注释、docstring、开发文档、提交说明、Pull Request、与维护者的对话、新撰写的用户可见文案.
> 不适用: 源码标识符、协议字段名、既有文案键、日志 event 名.
> 项目用词 (定名 / 义项分工) 见 [terms.md](terms.md).

## 语体

使用书面技术文档用语. 句子完整, 操作对象与结果明确. 禁止口语、语气词、以及省略到产生歧义的短句.

文档客观陈述产品与机制, 不预设需要被教育的读者, 不采用说教口吻.

标题用名词性名称, 不用「写什么」「要注意」这类课堂提问.

| 禁止 | 使用 |
| ---- | ---- |
| 搞、弄、搞定、弄成 | 写所执行的操作: 修改、实现、删除 |
| 那个、这种东西、后面没法 | 具体名称与可验证的后果 |
| 那些还要 | 上述路径、该文件、命中项 |
| 做什么 / 怎么做 / 不要这样做 | 规范、原则(方法)、约束(禁止) |

## 动词

谓语动词须为双音节或以上. 禁止单音节动作动词独立作谓语. 判断与存在 (是、有、无、在) 不在此列.

| 禁止 | 使用 |
| ---- | ---- |
| 扫 | 扫描、遍历 |
| 撞 | 违反、冲突、占用 |
| 进 | 进入、写入、移动至 |
| 丢、丢掉 | 排除、删除、丢弃 |
| 改 | 修改、更改 |
| 清 | 删除、清除 |
| 看 | 检查、依据 |
| 走 | 执行、采用、经由 |
| 跑 | 运行、执行 |
| 拿 | 读取、取得 |
| 放 | 放置、写入 |
| 收 | 收集、回收 |
| 挂 | 调用 |
| 设 | 设置、启用 |
| 绑 | 绑定 |
| 切 | 切换 |

「扫描」「遍历」为双音节, 可以使用.

## 禁止比喻

禁止借用其他学科、日常场景或其它软件产品的说法代替对系统机制的直接描述. 写对象、条件与后果.

已固定的领域词不算比喻: 刮削、落盘、回收、`.amane_trash`、路径模板、UNIQUE 约束.

| 禁止 | 使用 |
| ---- | ---- |
| 收口 | 未纳入索引或不匹配 glob 的文件同样进入清理清单 |
| 内存分流 | 一次遍历的结果在内存中分类后分别回收与落盘 |
| 真身 | 真实路径 (符号链接解析后的绝对路径) |
| 垫后 | 排在链尾、置于链尾 |
| 交付芯片、窥行、旁白 | 交付结果、按 id 取行、附加说明 |

## 字面英译

禁止按英文单词的日常义或者机械的将词组逐字译成中文, 会得到错义或拗口的词.

必须改写为对应的通用中文技术用语, 例如:

| 英文 | 错误 | 正确 |
| ---- | ---- | ---- |
| import | 进口 | 导入 |
| export | 出口 | 导出 |
| walk | 走 | 遍历 |
| fallback | 回落 | 回退 |
| swallow | 吞 | 忽略 |
| drop | 丢掉 | 丢弃、删除 |
| dest | dest、落点 | 目标/结果路径 |
| content type | 片种 | 类型; 完整时用影片类型、媒体类型或内容类型 |
| size | 体积 | 大小: 文件大小、视频大小、图片大小 |
| fetch | 抓取 | 获取 |
| egress / exit | 出口 | 网络出站写「出站」, 播放并发写「通道」, 数据产出写「输出」; 指对象的比喻用该对象的通用名 |

## 写什么

在文档和注释中只记录对象、条件、后果, 以及**仍生效的禁止事项**. 读者无需了解沿革.

特别需要注意的点必须写清. 写成客观禁止: 不允许做什么, 必要时补充机制上为何不行. 禁止用沿革口吻讲故事 (「之前这样做失败了, 所以后面不要」).

只记录**约束本身**. 禁止写没有信息量的实现描述 (复述导入语句、复述文件名、复述调用方).

| 禁止 | 使用 |
| ---- | ---- |
| 不要把 `src/amane/*.py` 当脚本交给 PyInstaller, 顶层脚本没有父包, 相对导入会失败 | PyInstaller 使用文件作为运行入口, 必须使用绝对导入 |
| Alembic 按路径加载, `__package__` 为空, 所以不要相对导入 | 迁移脚本必须使用绝对导入 — Alembic 按文件路径加载, 无法识别相对导入 |
| 不要在 handler 里直接 `create_task`, 必须走 followups | 后继任务只经 `TaskResult.followups` 进入完成事务 |

同一约束只完整陈述一次, 其他位置仅进行引用.

## 白名单

下列用语描述技术行为, 即使字面来自比喻或其他行业, 仍可使用:

踩坑、热插拔、热重载、挂载、回滚、降级、沙箱、快照、镜像、漏桶、扇出、逃逸.
