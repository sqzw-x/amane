# 播放

播放是可选功能, 用于在详情页直接观看预告片与插件提供的播放源; 本地视频的日常观看建议交给 [Emby / Jellyfin](media-server.md). 本页说明影片详情页的内置播放器: 预告片、由插件提供的播放源、播放源顺序, 以及快捷键与触屏手势. 适用于在浏览器、桌面客户端或 Android 客户端中直接观看影片的用户.

预告片与播放源共用同一个播放器, 支持直链视频与 HLS, 可选字幕与倍速, 在手机上开始播放即进入横屏全屏.

## 预告片 {#trailer}

影片有预告片时, 详情页封面中央显示 :material-play: 按钮, 点击后在封面位置播放, 右上角的 × 关闭. 预告片取字段优先级最高的来源给出的地址, 播放失败时显示「无法播放此预告片」.

!!! note
    预告片由浏览器直接从来源站点加载, 不经过 Amane 转发. 浏览器所在网络无法访问该站点时, 预告片无法播放.

## 播放源 {#sources}

详情页封面下方的「播放」面板播放影片正片. 播放源由插件提供, Amane 本身不内置播放源: 没有启用任何播放源插件时, 该面板不显示. 安装与启用插件见 [插件](plugins.md).

本地已入库文件同样经由播放源插件播放: 插件可以声明打开某个已入库的文件, 由 Amane 读取并输出给播放器.

### 选择播放源与码流

面板标题行有两级选择:

1. **播放源**: 只有一个播放源时显示其名称; 多个时平铺显示或以下拉菜单列出. 默认选中 [播放源顺序](#order) 中的第一个.
2. **码流**: 同一播放源可以给出多条码流 (如不同文件或分辨率). 默认选中第一条可用的码流; 不可用的码流标注「(当前不可用)」.

打开详情页时只列出播放源, 不向上游发出请求; 选中某个播放源后才查询它的码流.

### 失败与重试

播放窗口内直接显示失败原因:

| 提示 | 含义 | 重试 |
|------|------|------|
| 无法加载流列表 | 播放源查询码流失败 | 重新查询该播放源 |
| 该播放源当前不可用 / 插件给出的原因 | 该影片在此播放源没有可播放内容, 或插件报告故障 | 重新查询该播放源 |
| 无法播放此码流 (附 HTTP 状态或播放器错误) | 播放器加载失败 | 重新加载播放器 |
| 此播放源的媒体类型无法在页面内播放 | 码流不是浏览器可播放的视频或 HLS | 不提供 |

提示右侧的 :material-refresh: 按钮执行重试. 码流格式由插件与上游决定, Amane 不做实时转码.

## 播放源顺序 {#order}

启用两个及以上播放源插件后, 「插件」页顶部出现「播放源顺序」. 拖动调整顺序, 窄屏上用上移 / 下移按钮调整. 排在第一位的播放源即详情页默认选中的播放源.

!!! note
    播放源顺序保存在当前浏览器中, 不同浏览器与设备分别设置.

## 操作方式

### 控制条

控制条提供播放 / 暂停、时间、静音、音量、倍速 (0.5 / 0.75 / 1 / 1.25 / 1.5 / 2)、字幕 (码流带字幕时) 与全屏, 下方是进度条. 不支持定位的码流不显示进度条. 音量在浏览器中记住, 下次播放沿用.

### 快捷键

播放器获得焦点 (点击过画面) 后生效:

| 按键 | 动作 |
|------|------|
| ++space++ / ++k++ | 播放 / 暂停 |
| ++left++ / ++right++ | 后退 / 前进 5 秒 |
| 按住 ++right++ | 以 2 倍速播放, 松开恢复 |
| ++j++ / ++l++ | 后退 / 前进 10 秒 |
| ++up++ / ++down++ | 音量增减 5%, 按住连续调节 |
| ++m++ | 静音 |
| ++f++ | 全屏 |
| ++c++ | 字幕开关 |

### 鼠标

- 单击画面: 播放 / 暂停.
- 双击画面: 进入或退出全屏.
- 右键画面: 「复制时间戳」复制当前时间 (如 `12:34`), 可直接粘贴到 [评论](browse.md#comments) 中作为可点击的时间戳; 「复制当前时间的链接」复制带 `?t=秒数` 的详情页地址, 打开后定位到该时间.

### 触屏

| 手势 | 动作 |
|------|------|
| 点按 | 显示或隐藏控制条 |
| 双击 | 播放 / 暂停 |
| 长按 | 以 2 倍速播放, 松开恢复 |
| 横向滑动 | 拖动进度, 画面显示目标时间与偏移; 单次最多 90 秒 |
| 左半屏竖直滑动 | 调节亮度 |
| 右半屏竖直滑动 | 调节音量 |

- 在触屏设备上开始播放即进入全屏, 并在浏览器支持时锁定为横屏 (iOS Safari 不支持锁定, 由系统旋转决定); 播放结束自动退出全屏.
- 倍速在触屏上改为从右侧滑出的面板.
- Android 客户端中, 音量手势与按键调节系统媒体音量, 亮度手势调节本应用的窗口亮度, 离开播放器后恢复. 客户端说明见 [客户端](clients.md).

## 评论时间戳跳转

播放面板有可定位的码流时, 点击评论中的时间戳会使播放器定位到该时间并开始播放; 播放窗口已滚出视野时页面滚回播放器. 没有可定位的码流时, 时间戳显示为不可点击. 评论的写法见 [片库与浏览](browse.md#comments).
