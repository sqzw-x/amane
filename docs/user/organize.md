# 整理与路径模板

整理是 [媒体库](libraries.md) 的可选步骤, 作用于本地视频文件: 将已刮削的视频按路径模板放置到目标位置, 同时写出 NFO、封面、海报、剧照、预告片与字幕, 并可在库外创建 STRM 或符号链接. 本页说明整理的触发方式、路径模板语法、文件标记识别与水印; 媒体服务器的推荐配置见 [对接 Emby / Jellyfin](media-server.md).

## 整理流程

对每个已刮削的文件, 整理依次执行:

1. 按视频路径模板计算目标路径. 目标已被其它文件占用时跳过该文件, 不改动磁盘 (见 [路径冲突](#conflicts)).
2. 将封面、海报、剧照、预告片复制到附属资源模板指定的位置, 并为封面与海报叠加 [水印](#watermark). 缓存中缺失的资源当场下载.
3. 按「整理方式」放置视频.
4. 设置了链接路径模板时, 在库外创建 STRM 文件或符号链接 (见 [链接与 STRM](#links)).
5. 开启「写入 NFO」时写出 NFO.
6. 将视频同目录的字幕放置到字幕模板指定的位置 (见 [字幕](#subtitles)).
7. 更新文件记录的路径. 整理方式为「移动」时, 删除本次腾空的目录 (库根除外).

整理完成后, 任务结果列出已整理、跳过、冲突、失败的数量与「剪枝目录」数.

## 触发方式

| 方式 | 范围 |
|------|------|
| 库页面「整理落盘」 | 本库全部已刮削的文件 |
| 文件表勾选后「批量整理」 | 勾选的文件 |
| 「自动整理」 | 刚刮削成功的那一个文件 |

以下文件在整理时跳过: 尚未刮削的文件、命中文件黑名单或小于最小视频大小的文件、命中预告片正则的文件. 磁盘上已不存在的文件、已不在库根下或位于 `.amane_trash` 中的文件, 其记录在整理时删除.

### 自动整理 {#auto-organize}

在媒体库配置中开启「自动整理」后, 库内文件刮削成功时自动提交该文件的整理任务. 手动刮削、批量刮削、扫描与文件监控触发的刮削都适用; 自动整理排在手动提交的任务之后执行.

不关联媒体文件的刮削不触发自动整理, 包括从订阅发起的刮削与定时任务中的重新刮削.

!!! tip
    自动整理按当前模板直接写入磁盘. 建议先手动整理少量文件, 确认模板结果后再开启.

## 整理方式

| 整理方式 | 行为 |
|----------|------|
| 移动 (默认) | 将视频移动到目标路径, 并删除腾空的目录 |
| 复制 | 复制视频, 源文件保留 |
| 硬链接 | 在目标路径创建硬链接, 源文件与目标须在同一文件系统 |
| 符号链接 | 在目标路径创建指向源文件的符号链接 |

!!! warning "库内整理使用「移动」"
    复制、硬链接、符号链接在目标路径仍位于本库内时, 源路径上的文件保留. 记录改为指向目标路径之后, 再次扫描会把源路径再入库为另一个文件. 这三种方式只适用于视频模板指向库外路径的一次性写出; 为媒体服务器准备库外链接时, 使用 [链接路径模板](#links).

### 路径冲突 {#conflicts}

目标路径已被另一个文件占用时, 整理不改名、不覆盖, 也不写出该文件的图片与 NFO, 文件记录保持原路径. 冲突列在任务结果的「未处理的冲突」中:

- 「目标路径已有其它文件」: 视频的目标路径被占用.
- 「字幕目标路径已有其它文件」: 视频已整理, 但某个字幕的目标路径被占用, 该字幕留在原处.

任务结果最多列出 200 条冲突, 其余见任务日志. 冲突在用户处理之前, 每次整理都会再次报告. 源文件已在目标路径上 (含硬链接与符号链接指向同一文件) 不算冲突. 无法判定目标状态时计为失败.

## 路径模板

模板中的 `{占位符}` 替换为影片或文件的值, `/` 分隔目录层级. 模板在保存时校验语法, 有误时拒绝保存并给出原因.

![配置媒体库对话框中的路径模板与占位符](../assets/screenshots/organize-template.webp#only-light){ loading=lazy }
![配置媒体库对话框中的路径模板与占位符](../assets/screenshots/organize-template-dark.webp#only-dark){ loading=lazy }

| 模板 | 默认值 | 说明 |
|------|--------|------|
| 视频路径模板 | `{studio}/{number}/{number}[-CD{cd?}][-{sub?}].{ext}` | 相对路径相对库根; 绝对路径须在库根或 `AMANE_SAFE_DIRS` 范围内 |
| 链接路径模板 | 空 (不创建链接) | 必须是库外的绝对路径, 见 [链接与 STRM](#links) |
| STRM 内容模板 | 空 (写入视频绝对路径) | 仅链接方式为 STRM 时有效 |
| 封面模板 | `{link_dir}/thumb.jpg` | |
| 海报模板 | `{link_dir}/poster.jpg` | |
| 背景图模板 | `{link_dir}/fanart.jpg` | 内容与封面相同 |
| 剧照模板 | `{link_dir}/extrafanart` | 目录, 剧照按 `1.jpg`、`2.jpg` 依次命名 |
| NFO 模板 | `{link_dir}/{video_name}.nfo` | |
| 预告片模板 | `{link_dir}/trailer.mp4` | |
| 字幕模板 | `{link_dir}/{raw_srt_name}.{ext}` | |

附属资源模板在库配置的「附属资源模板」中展开, 留空使用默认值. 未设置链接时 `{link_dir}` 等于视频所在目录, 因此默认情况下附属文件写在视频旁边.

视频的扩展名始终取自源文件: 视频模板以 `.mp4` 结尾而源文件为 `.mkv` 时, 结果仍为 `.mkv`.

!!! note
    封面、海报、背景图与预告片的默认文件名固定. 多部影片整理到同一目录时会互相覆盖, 此时应在模板中使用 `{video_name}` 区分, 或保持每部影片一个目录.

### 占位符 {#placeholders}

| 占位符 | 说明 | 示例值 |
|--------|------|--------|
| `{number}` | 番号 | `MIDV-123` |
| `{prefix}` | 番号前缀 | `MIDV` |
| `{suffix}` | 番号去掉前缀后的剩余段 | `123` |
| `{title}` | 标题 | `Title Here` |
| `{actor}` | 第一位演员 | `Actor1` |
| `{actors}` | 全部演员, 逗号分隔 | `Actor1,Actor2` |
| `{actress}` | 第一位女演员 | `Actress1` |
| `{actresses}` | 女演员, 逗号分隔 | `Actress1,Actress2` |
| `{studio}` | 制作商 | `Studio Name` |
| `{publisher}` | 发行商 | `Publisher Name` |
| `{series}` | 系列 | `Series Name` |
| `{year}` | 发行年份 | `2024` |
| `{release}` | 发行日期 | `2024-01-15` |
| `{ext}` | 文件扩展名, 不含点; 字幕模板中为该字幕的扩展名 | `mp4` / `srt` |
| `{content_type}` | 内容类型 | `censored` `uncensored` `chinese` `western` `fc2` `amateur` `hentai` |
| `{cd?}` | 分集序号, 可空 | `1` / `2` / 空 |
| `{sub?}` | 中字标记, 可空 | `C` / 空 |
| `{mosaic?}` | 马赛克性质, 可空 | `censored` `uncensored` `cracked` `leaked` / 空 |
| `{def?}` | 分辨率 (文件名检测), 可空 | `8K` `4K` `1440p` `1080p` `720p` `480p` `HD` `SD` / 空 |
| `{raw_name}` | 源视频文件名, 不含扩展名 | `A/B.mp4` → `B` |
| `{raw_dir}` | 源文件父目录名 | `A/B/C.mp4` → `B` |
| `{video_dir}` | 整理后视频所在目录 | `/lib/Studio/MIDV-123` |
| `{video_name}` | 整理后视频文件名, 不含扩展名 | `MIDV-123-CD1-C` |
| `{video_relpath}` | 整理后视频相对库根的路径 | `Studio/MIDV-123/MIDV-123.mp4` |
| `{link_dir}` | 链接所在目录; 未设置链接时同 `{video_dir}` | |
| `{link_name}` | 链接文件名, 不含扩展名; 未设置链接时同 `{video_name}` | |
| `{raw_srt_name}` | 字幕源文件名, 不含扩展名 | `foo.zh.srt` → `foo.zh` |

部分占位符依赖整理过程中先算出的路径, 只能在特定模板中使用; 写在其它模板中输出 `Unknown`:

| 占位符 | 可用范围 |
|--------|---------|
| `{video_dir}` `{video_name}` `{video_relpath}` | 链接、附属资源、字幕、STRM 内容 |
| `{link_dir}` `{link_name}` | 附属资源、字幕、STRM 内容 |
| `{raw_srt_name}` | 仅字幕 |

取值规则:

- 影片缺少对应字段时输出 `Unknown`; 标题为空时 `{title}` 输出番号. 未知的占位符名同样输出 `Unknown`.
- `{prefix}` / `{suffix}` 从刮削所得的番号拆分, 不依据源文件名: `MIDV-123` → `MIDV` / `123`, `MKY-HS-001` → `MKY-HS` / `001`.
- `{actress}` / `{actresses}` 排除已标为男性的演员, 女性与性别未知的演员保留.
- `{mosaic?}` 优先取文件的马赛克标记 (见 [文件标记](#file-markers)); 没有标记时继承影片类型: 有码影片为 `censored`, 无码影片为 `uncensored`, 国产、FC2、欧美等为空.
- `{title}` 与演员类占位符超过 200 字节时截断, 末尾补 `…` (计入上限), 截断不切开多字节字符.
- `{title}` `{actor}` `{actress}` `{studio}` `{publisher}` `{series}` `{release}` 的值中, 路径分隔符、`:` 与控制字符替换为空格, `*` `?` `"` `<` `>` `|` 被删除.
- 路径模板拼出的每个路径段中, 控制字符替换为空格, 段尾的 `.` 与空格被去掉, 空段被省略. 这些字符会使目录创建失败, 或使实际创建的目录名与记录不一致.

### 可选组

`[...]` 将模板的一段包裹为组: 组内直接包含的占位符全部为空时, 整组省略. 用于分集、中字等可能不存在的属性:

```text
{number}[-CD{cd?}][-{mosaic?|cracked=U,censored=}{sub?}].{ext}
```

| 源文件 | 结果 |
|--------|------|
| `MIDV-123-U-C-CD2.mp4` | `MIDV-123-CD2-UC.mp4` |
| `MIDV-123-U.mp4` | `MIDV-123-U.mp4` |
| `MIDV-123-C.mp4` | `MIDV-123-C.mp4` |
| `MIDV-123.mp4` | `MIDV-123.mp4` (不残留 `-`) |

组内有一个占位符非空即输出整组, 其中为空的占位符输出空串. 嵌套的组各自判断.

双层方括号 `[[...]]` 的省略规则相同, 有值时结果外加一层方括号:

```text
{number}[[{def?}]].{ext}
```

检测到 4K 时为 `MIDV-123[4K].mp4`, 未检测到时为 `MIDV-123.mp4`.

### 值映射

`{name|原值=输出,原值=输出}` 将占位符的值改写为自定义文本:

```text
{mosaic?|censored=有码,uncensored=无码,cracked=U,leaked=流出}
{mosaic?|=未知}
{content_type|censored=有码,uncensored=无码}
{def?|4K=2160p,1080p=FHD}
```

- 未列出的值保持原样.
- `{name|=缺省}` 将空值映射为缺省文本, 如国产、FC2 影片无法判定马赛克性质时.
- 可以映射为空串, 配合可选组使某个值不出现在路径中.
- `{content_type}` `{mosaic?}` `{def?}` `{sub?}` 的映射键必须是上表中的规范值, 写错时拒绝保存. 表单中悬停占位符徽章可查看可映射的规范值.

目录段与文件名段可分别映射, 例如目录使用规范值, 文件名使用短标记:

```text
{mosaic?}/{number}[-{mosaic?|censored=,uncensored=无码,cracked=U,leaked=流出}].{ext}
```

| 源文件 (有码影片) | 结果 |
|--------|------|
| `MIDV-123.mp4` | `censored/MIDV-123.mp4` |
| `MIDV-123-無碼.mp4` | `uncensored/MIDV-123-无码.mp4` |

## 文件标记 {#file-markers}

分集、中字、马赛克标记与分辨率从源文件路径识别, 只描述这一份文件, 与影片本身的类型无关.

| 标记 | 识别规则 | 占位符 |
|------|---------|--------|
| 分集 | 文件名中的 `-CD1` / `_CD1` / `.CD1`、`-PART1`, 文件名末尾的 `-A` / `-B` 与 `-1` 至 `-9`; 文件名无标记时, 直接父目录名为 `CD1` / `PART1` 也可识别 | `{cd?}` |
| 中字 | 文件名含 `-C` 或 `-UC`, 或含「字」「幕」「中」「文」, 或视频同目录有外挂字幕 | `{sub?}` |
| 破解 | 文件名含 `破解` `克破` `CRACKED`, 或 `-U` / `-UC` | `{mosaic?}` |
| 流出 | 文件名含 `流出` `LEAKED` | `{mosaic?}` |
| 无码 | 文件名含 `無碼` `无码` `UNCENSORED` | `{mosaic?}` |
| 分辨率 | 文件名含 `8K`、`4K` / `2160P`、`1440P`、`1080P`、`720P`、`480P`、`HD`、`SD`, 取最高的一档 | `{def?}` |

- 字母分集只支持 `-A` 与 `-B`: `-C` 表示中字.
- 文件名没有马赛克标记时, 依据目录名判定: 某一层目录名整段为 `uncensored` `无码` `無碼` `cracked` `破解` `leaked` `流出` (可带方括号或圆括号) 时适用, 取最近的一层.
- 分辨率允许后接帧率 (`1080p60`); `HD-123` 这类番号前缀不视为分辨率.

## 字幕 {#subtitles}

整理时, 视频同目录 (不递归子目录) 中扩展名属于库「字幕扩展名」的文件随视频一同整理. 字幕扩展名留空则不处理字幕. 字幕本身不入库.

- 字幕文件名能解析出番号时, 必须与视频番号相同, 再按分集配对.
- 解析不出番号时按分集配对: 带分集标记的字幕跟随同一分集的视频; 无分集标记的字幕跟随无分集或 CD1 的视频.
- 匹配的字幕全部整理, 默认保留原文件名与扩展名, 放在 `{link_dir}`. 字幕模板中 `{ext}` 与 `{raw_srt_name}` 取自字幕文件, `{raw_name}` 与 `{raw_dir}` 仍取自视频.
- 字幕使用与视频相同的整理方式.

视频同目录存在任一字幕扩展名的文件时, 该视频即标记为中字: `{sub?}` 输出 `C`, 封面与海报叠加中字水印, 片库同样显示中字标识. 该判定只依据扩展名, 不检查字幕的文件名与语言. 外挂字幕标记在入库、扫描新文件与整理后更新.

## 链接与 STRM {#links}

链接路径模板用于在库外创建指向库内视频的链接, 使视频与 NFO、图片分开存放. 典型场景是视频位于网盘挂载目录, 媒体服务器读取本地的链接目录; 配置示例见 [对接 Emby / Jellyfin](media-server.md#cloud).

| 设置 | 说明 |
|------|------|
| 链接路径模板 | 链接文件的路径, 如 `/local/emby/{studio}/{number}/{video_name}.{ext}`. 必须是库外的绝对路径; 在 Docker 等启用了路径校验的环境中, 还须位于 `AMANE_SAFE_DIRS` 之内 |
| 链接方式 | 「STRM 文件」(默认) 或「符号链接」 |
| STRM 内容模板 | `.strm` 文件的内容. 留空时写入整理后视频的绝对路径 |

- 链接方式为 STRM 时, 链接文件的扩展名固定为 `.strm`.
- 设置链接后, 默认附属资源模板以 `{link_dir}` 为根, NFO、图片与字幕写入链接目录, 视频旁边不再写附属文件. 需要留在视频旁边的项, 将模板改为以 `{video_dir}` 为根.
- 链接已存在且内容一致时不改写; 已有的 `.strm` 内容不同时改写, 已有的符号链接指向不同时替换. 目标位置是其它普通文件时不覆盖, 该文件计为失败, 下次整理时重试.

STRM 内容模板与路径模板的占位符相同, 但只占一行, 不省略空段、不截断字段, 因此可以写入 URL:

```text
https://example.com/{video_relpath}
```

整理后视频为 `ABC-123/ABC-123.mp4` 时, STRM 内容为 `https://example.com/ABC-123/ABC-123.mp4`. 模板引用 `{video_relpath}` 时视频必须整理在本库内, 否则该文件整理失败. 占位符的值原样写入, 不进行 URL 编码.

!!! warning "库外链接不由 Amane 清理"
    在媒体库中删除视频只删除库内的文件, 库外链接目录中的 STRM、NFO 与图片保留原处, 需要自行清理.

## 附属资源

「整理时复制」决定哪些已下载资源复制到附属资源模板指定的位置: 封面、海报、剧照、预告片. 新建媒体库时默认勾选除预告片外的三项.

- 背景图与封面内容相同, 随封面一同写出.
- 影片没有海报而「设置 → 影片刮削 → 裁切海报」开启时, 从封面裁切出海报.
- 资源缓存中不存在的文件在整理时下载.
- 每次整理都重新写出图片与 NFO, 覆盖目标位置的同名文件.
- 预告片取自刮削下载的预告片, 不使用库目录中已有的预告片文件.

NFO 的内容与媒体服务器侧的布局见 [对接 Emby / Jellyfin](media-server.md#nfo).

## 水印 {#watermark}

整理时可在库内的封面与海报副本上叠加角标, 标示中字、无码、破解、流出与分辨率. 资源缓存中的原图不受影响, 片库中的角标显示也与本设置无关.

在「设置 → 水印」配置:

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 启用水印 | 关闭 | 关闭时整理不叠加水印 |
| 水印大小 | `0.08` | 角标高度相对图片高度的比例, 范围 0.03 至 0.25 |
| 水印位置 | 全部左上 | 为中字、无码、破解、流出、分辨率分别选择左上、右上、左下、右下 |

- 中字依据 [文件标记](#file-markers) 中的中字判定, 含外挂字幕.
- 无码: 影片类型为无码, 或文件带无码标记.
- 破解、流出依据文件的马赛克标记; 分辨率依据文件名检测出的档位.
- 同一角有多个角标时, 按中字 → 无码 → 破解 → 流出 → 分辨率的顺序向内排列.
- 水印只在整理时写入. 修改设置后, 需重新整理才会作用于已整理的影片. 每次整理都从原图重新生成, 水印不会重复叠加.

### 内置与自定义水印

Amane 内置以下角标, 每个分辨率档位均有对应图片. 在数据目录的 `watermarks/` 下放置同名 PNG 即可替换内置样式:

| 文件名 | 角标 |
|--------|------|
| `subtitle.png` | 中字 |
| `uncensored.png` | 无码 |
| `cracked.png` | 破解 |
| `leaked.png` | 流出 |
| `8k.png` `4k.png` `1440p.png` `1080p.png` `720p.png` `480p.png` `hd.png` `sd.png` | 分辨率 |

- 文件名必须为小写.
- 透明边缘会被裁掉, 再按水印大小缩放, 宽度按比例计算.
- 自定义文件无法读取时回退内置图片.
- 自定义文件在下次整理时生效, 不需要重启.
