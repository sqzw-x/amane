# 智能体

Amane 内置一个对话式智能体, 在首页 (侧栏「浏览 → Amane」) 用自然语言查询与管理片库; 也可以把自己常用的命令行智能体接入实例, 由它通过 Amane CLI 执行同样的操作. 本页适用于需要配置、使用或接入智能体的用户.

## 快速开始

1. 打开「设置 → 智能体」, 填写「API 类型」「API 密钥」「API 端点」「模型」并保存.
2. 进入侧栏「Amane」, 在输入框描述需求, 按 Enter 发送 (Shift+Enter 换行).
3. 涉及删除或合并的操作, 在对话中点击「批准」后才会执行.

!!! note "未配置时"
    未填写「API 密钥」时, 首页对话不可用. 外部智能体接入不依赖这项配置, 见 [外部智能体接入](#external).

## 对话能力 {#capabilities}

智能体读取片库的方式是只读查询, 修改只经由下表中的封装操作执行, 不直接修改数据库. 它可以完成的工作按对象分组如下:

| 对象 | 可执行的操作 |
|------|-------------|
| 片库检索 | 按任意条件查询影片、演员、分类、文件与任务数据, 交付为[查询预设](#presets) |
| 影片 | 修改字段、从刮削来源合并字段、批量添加或移除用户标签、提交刮削、删除 |
| 演员 | 修改人物字段、查询 / 添加 / 移除别名、切换展示名、提交演员刮削 |
| 分类 | 重命名、合并、删除, 查看与删除分类规则 |
| 媒体库 | 创建、修改、删除, 提交扫描 |
| 订阅源 | 创建、修改、删除、立即拉取, 对历史条目批量忽略 / 已读 / 删除 / 刮削 |
| 定时任务 | 创建、修改名称 / 运行时间 / 启用状态、立即触发、删除 |
| 任务 | 提交任意类型的任务、取消排队中或运行中的任务、重试失败任务 |

智能体只提交任务, 不在对话中直接执行刮削或整理; 任务进入[任务队列](tasks.md)后由任务引擎执行, 进度在「任务」页查看.

!!! info "能力边界"
    - 智能体不能修改「设置」中的任何配置.
    - 智能体修改的影片与演员字段按手动编辑处理, 字段随之锁定, 之后的自动刮削不再覆盖它们. 锁定规则见 [片库与浏览](browse.md).
    - 定时任务创建后只能修改名称、运行时间与启用状态; 修改任务类型或参数须删除后重建.

### 查询预设 {#presets}

检索类请求的结果以查询预设交付, 在回复中显示为一行操作:

| 按钮 | 作用 |
|------|------|
| 查看数据 | 在新页面以数据表浏览全部结果行 |
| 在片库中打开 / 在演员中打开 | 结果是影片或演员时出现, 把结果作为片库或演员页的筛选条件打开, 可与其它筛选同时使用 |
| 保留预设 | 使预设脱离会话长期保存, 出现在「查询预设」页 |
| 下载结果 | 下载结果的 JSON 文件 |

未保留的预设属于当前会话, 删除会话时一并删除; 会话列表上方的「查询预设」按钮列出本会话交付的预设. 预设保存的是查询条件, 每次打开都按当前数据重新运行. 手动创建与管理预设见 [片库与浏览](browse.md).

## 思考过程与用量 {#trace}

回复中的思考与工具调用折叠为一行摘要, 例如「思考 2 段 · 调用了 3 个工具」, 进行中时显示「思考中…」或「工具运行中…」. 展开后可检查每次工具调用的「参数」与「结果」.

每次模型请求之后显示一组用量标记, 回合结束时显示整轮汇总:

| 标记 | 含义 |
|------|------|
| 请求 | 本回合的模型请求次数 (仅汇总) |
| 输入 / 输出 | 未命中缓存的输入 token 与输出 token |
| 缓存读 / 缓存写 | 供应商提示词缓存的读取与写入 token |
| 缓存命中 | 缓存读占全部输入的比例 (仅汇总) |
| 耗时 | 单次请求的耗时 |

鼠标悬停在标记上显示精确数值. 供应商未返回的项不显示.

### 思考强度

输入框左下角的「思考」菜单设置当前会话的思考强度, 可选「默认」「关闭」「最低」「低」「中」「高」「最高」. 「默认」沿用「设置 → 智能体 → 默认思考强度」; 选择其它值只影响当前会话.

## 审批 {#approval}

不可撤销的操作在执行前暂停, 工具卡片中显示操作说明与「批准」「拒绝」按钮. 需要审批的操作:

- 删除影片 (单条与批量).
- 合并分类、删除分类、删除分类规则.
- 删除媒体库 (只删除索引, 不删除磁盘文件).
- 删除订阅源、删除订阅源的历史条目.
- 删除定时任务.
- 智能体主动标记为耗时较长的查询.

其余修改 (字段编辑、合并影片字段、用户标签、别名、提交与取消任务等) 不经审批直接执行.

审批规则:

- 一次回复中有多项待批操作时, 须对每一项作出决定后才统一提交; 「批量批准」对全部待批项一次性批准.
- 拒绝后智能体收到「用户拒绝执行」的结果, 继续本轮回复.
- 待批状态保存在服务端, 刷新页面或切换会话后仍可审批; 会话列表中待审批的会话带有「批准」标记.

## 会话管理 {#sessions}

- 在首页直接输入即开始新会话, 标题按首条消息自动生成. 已有会话时, 左侧会话栏 (窄屏为「会话」按钮) 列出全部会话, 「新对话」创建新会话.
- 会话条目的菜单提供「重命名」与「删除会话」. 删除会话同时删除其中未保留的查询预设.
- 回合在服务端运行: 关闭或刷新页面不会中断, 重新打开会话即继续显示进度. 只有点击「停止」才会终止当前回合.
- 会话历史保存在数据目录的 `agent/sessions/` 下, 属于用户数据, 重启后保留.

## 设置 → 智能体 {#settings}

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| API 类型 | Responses | 上游协议: Chat (OpenAI Chat Completions)、Responses (OpenAI Responses)、Anthropic (Anthropic Messages). 供应商支持时应优先使用 Responses 或 Anthropic |
| API 密钥 | 空 | 供应商的密钥. 为空时首页对话不可用 |
| API 端点 | `https://api.openai.com/v1` | 原样交给对应协议的客户端, 不做改写. 选择 Anthropic 时须填写 Anthropic 协议的端点 |
| 模型 | `gpt-4o-mini` | 供应商的模型名 |
| 默认思考强度 | 不设置 | 新会话的思考强度; 不设置时请求中不携带思考参数. 可在对话中按会话修改 |
| 最大输出 token | 128000 | 单次回复的输出上限. 超过模型上限时上游拒绝请求 |
| 每秒请求上限 | 2 | 对供应商的请求速率上限, 过高可能触发限流 |

智能体与「设置 → LLM 翻译」使用各自独立的凭据、模型与限速. 保存后立即生效, 无需重启.

??? note "仅在配置文件中可修改的项"
    以下字段不在设置页显示, 可在数据目录的 `config.toml` 的 `[agent]` 段修改:

    | 字段 | 默认值 | 说明 |
    |------|--------|------|
    | `sql_timeout_ms` | 1000 | 智能体与查询预设的查询超时 (毫秒) |
    | `result_cache_ttl_s` | 3600 | 查询结果内存缓存的存活秒数, 过期后重新运行 |
    | `result_cache_max_entries` | 64 | 查询结果缓存的最大条目数 |
    | `history_ttl_s` | 3600 | 会话历史在内存中的存活秒数, 逐出后按需从磁盘读取 |
    | `history_max_sessions` | 32 | 同时保留在内存中的会话历史数 |

## 外部智能体接入 {#external}

Amane 可以交给用户自己的命令行智能体管理. 接入由两部分组成: Amane CLI (单文件命令行程序, 负责保存凭据与调用实例), 以及由 CLI 生成的 `amane` skill (告诉智能体如何使用 CLI). 外部智能体可调用的操作与[对话能力](#capabilities)相同.

### 接入步骤

1. 打开侧栏「用户手册」, 在「配置外部 Agent」一节点击「复制」.
2. 把复制的文本发送给智能体. 文本是一条指向本实例 `/api/agent-guide` 的指令, 智能体读取后按其中的步骤操作.
3. 智能体安装 CLI: 从 GitHub Releases 下载对应平台的 `amane` 程序并校验 SHA256, 安装位置与修改 PATH 会先征求用户同意.
4. 智能体登录实例, 为该实例写入一份 profile (见下文 [Token 配置](#cli-token)).
5. 智能体执行 `amane skill install` 生成 skill (默认写入 `~/.agents/skills/amane`), 部分智能体工具需要重启后才能识别.

!!! warning "CLI 的下载方式"
    CLI 提供 Linux / macOS 的 amd64 与 arm64, 以及 Windows amd64 版本. macOS 上必须用 `curl` 或 `wget` 下载; 浏览器下载的文件带有隔离属性, Gatekeeper 会阻止其运行.

也可以手动完成上述步骤:

```bash
amane login --server <实例地址> --profile <名字>   # 写入 profile, 终端输入 token 时不回显
amane doctor --profile <名字>                      # 自检: 实例可达性、token、版本
amane skill install                                 # 生成 skill 文件, 不连接实例
```

CLI 的其它命令: `catalog` (工具索引)、`call` (调用工具)、`wait` (等待任务结束)、`schema` (库结构摘要)、`api` (只读 GET 请求)、`config list` / `config delete` (管理 profile)、`upgrade` (自我更新). 完整用法见 `amane --help`.

### Token 配置 {#cli-token}

CLI 用 [API Token](configuration.md) 访问实例, token 保存在 CLI 自己的配置文件中, 不出现在对话里:

| 平台 | 配置文件 |
|------|---------|
| macOS / Linux | `~/.config/amane/cli.json` (Linux 遵循 `$XDG_CONFIG_HOME`) |
| Windows | `%LOCALAPPDATA%\Amane\cli.json` |

文件权限为 0600. 每个实例一份 profile, 每条命令都须用 `--profile` 指定, 不存在「当前实例」.

=== "实例在本机"

    本机安装过桌面版时, `amane login` 自动读取桌面版留下的 token 并当场验证, 无需粘贴.

=== "实例在其它机器"

    由用户在自己的终端执行 `amane login --server <实例地址> --profile <名字>`, 按提示粘贴 token. token 可在桌面版菜单「复制 API Token」或实例的启动日志中取得, 获取方式见 [配置参考](configuration.md).

!!! danger "安全提示"
    - 不要把 token 粘贴给智能体. 接入指引已要求智能体不得索要 token, 也不得从文件、日志或进程环境中查找 token.
    - 实例地址是非本机的明文 `http` 时, token 以明文传输, CLI 会给出提示. 远程访问应使用 HTTPS 或反向代理, 见 [客户端](clients.md).

### 权限说明 {#external-permission}

外部智能体可以执行内置智能体的全部操作, 且**服务端不设审批**: 上文[审批](#approval)中列出的删除与合并操作会直接执行.

skill 要求智能体在删除、合并、批量修改与耗时较长的查询之前, 先向用户说明影响范围并取得明确同意; 但这只是写给模型的文本约束, 服务端不做校验. 应选用指令遵循能力较好的模型, 避免误操作导致数据丢失.

外部调用没有会话: 交付的查询预设直接保留, 出现在「查询预设」页.
