# 常见问题

## 扫描不到文件

按顺序核对 [媒体库管理](libraries.md) 里的设置:

- 文件扩展名不在媒体扩展名内 (默认只含常见视频后缀).
- 文件位于库根之外, 或子目录未开启递归扫描.
- 文件名命中文件黑名单正则, 或大小低于最小视频大小: 这类文件进清理清单, 不入库.
- 路径位于 `.amane_trash` 内: 该目录任意深度恒被忽略.
- CloudDrive2 挂载的库需要填写 CloudDrive 路径, 否则路径无法对应.
- 文件名不含番号时仍会入库, 但不会被自动刮削.

## 刮削不到元数据或字段不全

见 [刮削指南](scraping.md):

- 该内容类型的类型路由里没有可用的站点.
- 字段优先级与字段排除把取值限制到了少数站点.
- 站点不可达或被拦截: 在「设置 → 网络」的检测页逐个来源查看结论.

## 忘记 API Token

见 [开始使用](index.md): 桌面端在菜单栏或托盘图标里复制; 容器端在启动日志或数据目录的 token 文件中查看.

## 整理后源目录还在

整理方式决定源文件是否离开原处: 移动会移走源文件, 复制、硬链接与符号链接会保留源文件. 关联文件 (NFO / 图片 / 字幕) 与空目录的清理见 [媒体库管理](libraries.md) 的清理无效文件一节.

## 封面、海报与水印

图片在刮削时下载, 也可以在访问影片详情页时按需下载; 裁切海报与叠加水印的开关见 [配置指南](configuration.md).
